## Scientific status

QFG Dynamics is a research workbench. It contains numerical solvers, reduced models, proxy metrics and conditional bridges. Numerical stability, convergence and visualization are not by themselves experimental validation or proof of a first-principles physical theory.

## Versioning

The documentation targets **1.0.0-alpha**. UI names, defaults and operator locations may change in later alpha builds; the installed UI and exported session metadata are authoritative for the exact installed build.
